# Future Plans

This file is the parking lot for product directions outside the Android
reminder POC. Items here are not active scope until a later plan promotes them.

## Phase 5 Feature Freeze

Feature additions are frozen from **2026-08-24 through 2026-09-07**. During
this window, active code changes are limited to Android dogfood defects in
capture reliability, reminder scheduling, location/geofence behavior,
permissions, sync reliability, and wrong-reminder correction. Every other
request stays in this file until the freeze ends and the POC evidence is
reviewed.

## Deferred Product Directions

- Habits: elastic habits, cadence authoring, habit completions, rewards, and
  habit-specific analytics.
- Fresh Start: shame-free reset flows and missed-habit recovery.
- Done list: a dedicated historical mirror across habits and tasks.
- Goals and Goal Sage: goal planning, target dates, progress tracking, and
  goal-specific AI support.
- Notes: capture-to-note storage and note review.
- Focus/body double: focus sessions, body-double sessions, session capture, and
  focus completion flows.
- App blocking: block lists, enforcement, bypass handling, and related settings.
- Vibe checks: emotional state capture and related event streams.
- Persona chat: chat UI, conversational turns, persona behavior, and memory
  presentation.
- TTS/talk-back: spoken responses, voice persona, and audio response playback.
- Insights: monthly summaries, behavioral insights, and trend reports.
- iOS proof: iOS capture, scheduler, notification, and location behavior.
- Additional themes: visual themes beyond the current shell/theme foundation.
- Broad capture decomposition: non-reminder capture inbox, multi-kind review,
  and automatic extraction into habits, goals, notes, or other entities.

## Promotion Rule

Promote an item only by updating the POC spec/phases or creating a new post-POC
plan. Until then, active code and navigation should stay reminder-first.
